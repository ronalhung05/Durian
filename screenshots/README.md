# Product Screenshots

This directory contains screenshots of the Durian Leaf Disease Detection app to showcase the final product.

## Screenshots to Include

For the best presentation to interviewers, consider adding the following screenshots:

### 1. **Authentication Screens** (`auth_*.png`)
- Login screen
- Sign up screen
- Password reset screen (if applicable)

### 2. **Home/Dashboard** (`home_*.png`)
- Main dashboard view
- Navigation menu
- User profile section

### 3. **Disease Detection** (`detection_*.png`)
- Camera interface for capturing leaf images
- Image selection from gallery
- AI analysis in progress
- Detection results with disease identification
- Confidence scores/accuracy indicators

### 4. **Disease Information** (`disease_info_*.png`)
- Detailed disease information screen
- Causes and symptoms
- Treatment recommendations
- Prevention tips

### 5. **Plant Library** (`library_*.png`)
- Plant database browsing interface
- Plant detail pages
- Search and filter functionality

### 6. **Weather Integration** (`weather_*.png`)
- Weather dashboard
- Location-based weather data
- Agricultural insights

### 7. **Additional Features** (`misc_*.png`)
- Settings screen
- History/scan history
- Any other unique features

## Naming Convention

Use descriptive names for your screenshots:
- `01_login.png` - Login screen
- `02_signup.png` - Sign up screen
- `03_home_dashboard.png` - Home screen
- `04_camera_capture.png` - Camera interface
- `05_detection_results.png` - Disease detection results
- `06_disease_details.png` - Disease information
- `07_plant_library.png` - Plant library
- `08_weather.png` - Weather integration
- etc.

## Image Guidelines

- **Format**: PNG or JPEG
- **Recommended Size**: 1080x2400 (or your app's aspect ratio)
- **Quality**: High resolution for clarity
- **Content**: Ensure screenshots show actual app functionality with realistic data

## How to Add Screenshots

1. Take screenshots from your device/emulator
2. Save them to this directory with descriptive names
3. The README.md in the root will automatically reference these images
